# 6.1. Conclusiones

* La implementación de la plataforma Smart Home HERA permite mitigar la problemática de fragmentación en la gestión de dispositivos IoT, logrando centralizar el control de equipos de múltiples fabricantes en una única interfaz web intuitiva y eficiente.

* La aplicación del enfoque Lean UX resultó fundamental para alinear el diseño del producto con las necesidades reales de los usuarios, validando mediante hipótesis la importancia crítica del monitoreo energético y la automatización de rutinas para mejorar la calidad de vida en el hogar.

* La arquitectura de software definida, que integra una API RESTful protegida mediante tokens JWT y un diseño responsivo basado en un sistema de diseño propio, garantiza una solución técnica robusta, segura y escalable que cumple con los estándares de ingeniería de software actuales.

* Los resultados obtenidos durante el primer sprint confirman la viabilidad del proyecto, habiendo logrado el despliegue exitoso de una landing page funcional con soporte bilingüe y estableciendo las bases técnicas para el dashboard operativo de gestión de dispositivos.

* El desarrollo del proyecto por parte del equipo Dev-il-team permitió alcanzar satisfactoriamente el Student Outcome ABET 5, demostrando una gestión efectiva de tareas, liderazgo compartido y un entorno de colaboración inclusivo para el cumplimiento de los objetivos académicos propuestos.

## Contraste con la validación

* Los Problem Statements, Assumptions e Hypotheses planteados en el proceso Lean UX (sección 1.2) se contrastan con las Validation Interviews (sección 5.3). Las hipótesis centrales —la necesidad de centralizar el control de dispositivos y el valor del monitoreo energético y la automatización— se mantienen como las de mayor prioridad percibida por los segmentos entrevistados.

## Recomendaciones y trabajo futuro

* Desplegar la primera versión de los Web Services (Hera-Backend) e integrar el frontend con la API real, reemplazando progresivamente la Fake RESTful API.
* Incorporar pruebas unitarias y de integración/aceptación en el repositorio de Web Services para asegurar la calidad del Server Side.
* Completar las funcionalidades de mayor valor pendientes del Product Backlog (automatizaciones avanzadas, analítica energética y gestión de suscripciones Premium).
* Reforzar la validación con usuarios mediante entrevistas adicionales y evaluación heurística, retroalimentando el diseño de la plataforma.
* Evaluar una versión mobile/responsive más completa y mejoras de accesibilidad acordes a los segmentos objetivo.
