## 2.4. Big Picture Event Storming

En esta gráfica mostramos los eventos que sucederían cuando el usuario use nuestra plataforma. Los primeros dos eventos están en orden cronológico, pero los siguientes dependen de que el usuario elija dichas funciones. Para el event storming usamos los colores correspondientes: **naranja** para eventos, **azul** para acciones, **amarillo** para actores y **morado** para políticas.

Representación de los eventos del sistema: Inicio de sesión -> Ingreso satisfactorio -> Consulta de info de dispositivos -> Observación de seguridad -> Regulación de temperatura -> Verificación de consumo.
