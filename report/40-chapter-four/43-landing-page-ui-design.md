## 4.3. Landing Page UI Design

La propuesta de interfaz de usuario (UI) para la landing page de Hera traduce de forma visual las decisiones definidas en la arquitectura de información y el enfoque centrado en el usuario. Desde el primer contacto, la interfaz busca transmitir elegancia, innovación, seguridad y control, alineados con el propósito de la plataforma: gestionar smart homes de forma eficiente mediante soluciones domóticas centralizadas.

La estructura de la landing page organiza el contenido en secciones clave como Home, Servicios, Beneficios, Automatización Inteligente y Contacto, permitiendo que el usuario comprenda rápidamente el valor de la plataforma. Esta distribución responde a principios de jerarquía visual, accesibilidad y navegación intuitiva.

A nivel visual, se utiliza una combinación de colores sofisticados como azul nocturno, dorado y tonos neutros, junto con tipografías modernas y elementos interactivos como botones y llamadas a la acción que guían al usuario hacia funciones principales como solicitar una demo o conocer los servicios.

De esta manera, la landing page no solo refleja la identidad visual de Hera, sino que también mejora la experiencia del usuario y refuerza la percepción de una plataforma moderna, confiable y orientada al hogar inteligente.

### 4.3.1. Landing Page Wireframe

La sección presenta la estructura inicial de la página principal de Hera, diseñada con el objetivo de ofrecer una experiencia clara, elegante e intuitiva centrada en el usuario. El wireframe permite visualizar la distribución de los elementos principales de la landing page antes de su desarrollo final, asegurando una correcta jerarquía visual, navegación eficiente y adaptación a distintos dispositivos.

En esta propuesta se incluyen secciones clave como el encabezado de navegación (header), la sección principal de presentación (hero section), los servicios de smart home, los beneficios de la automatización inteligente, el monitoreo de seguridad y consumo energético, así como una llamada a la acción orientada a solicitar una demo o contactar con la empresa.

El diseño prioriza la simplicidad visual, el acceso rápido a la información relevante y una estructura responsive tanto para Desktop Web Browser como para Mobile Web Browser. Además, se aplican principios de diseño inclusivo, usabilidad y arquitectura de información, permitiendo una experiencia consistente y accesible para todos los usuarios.

El wireframe presentado para la versión Desktop Web Browser muestra la distribución estructural de la landing page de Hera, permitiendo visualizar la jerarquía de cada sección y la relación entre los elementos principales de navegación e interacción.

En la parte superior se ubica el navbar principal con el logotipo, menú de navegación y el botón de llamada a la acción “Solicitar Demo”, facilitando el acceso rápido a las secciones más importantes. La hero section destaca la propuesta de valor principal de la plataforma junto con botones orientados a la conversión del usuario.

Posteriormente, se presentan las secciones de servicios, beneficios clave y funcionamiento del sistema, organizadas de forma clara para mejorar la comprensión de la solución domótica ofrecida. Finalmente, se incorpora una sección de cierre con llamada a la acción final y un footer informativo que reúne enlaces rápidos, contacto y redes sociales.

Esta estructura permite una navegación intuitiva, mejora la experiencia del usuario y establece la base funcional para el desarrollo posterior del mock-up visual de alta fidelidad.
