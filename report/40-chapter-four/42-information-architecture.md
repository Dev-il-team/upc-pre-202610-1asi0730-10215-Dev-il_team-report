### 4.2.2. Labeling Systems

Para la interfaz de Hera, hemos representado las etiquetas de manera jerárquica y organizada para ofrecerle al usuario una experiencia de uso dinámica.

En la landing page observamos que el encabezado cuenta con 5 botones que llevan a sus respectivas secciones.



**Servicios:** Esta etiqueta indica las diferentes propuestas de valor que ofrece Hera para la automatizaciones de hogares inteligentes.

**Beneficios:** Enumeramos las características que obtendrá si adquiere el servicio de Hera.

**Planes:** Muestra una comparación del plan básico con el plan premium.

**Contacto:** Esta sección incentiva al usuario a que cree una cuenta para posteriormente contratar el servicio.

Por lo que podemos concluir que estas etiquetas indican de manera concisa a lo que llegaremos si presionamos dicho botón.

Luego con el frontend de la aplicación web, observamos unas 5 etiquetas, pero a la izquierda comenzamos con el ícono que lleva a la pantalla principal.



**Consumption summary:** Esta etiqueta redirige a una pantalla donde se muestra el resumen numérico del consumo de energía.

**Notifications:** Este apartado mostrará las notificaciones una debajo de otra.

**Routines:** Lleva a una pantalla que recopila todos los procesos automatizados creados con su respectivo artefacto.

**My subscription:** Esta etiqueta representa que se dará información del plan actual

**My profile:** Nos lleva a una pantalla que resume mediante un gráfico circular el consumo de electricidad por dispositivo.

### 4.2.3. SEO Tags and Meta Tags

Para asegurar la correcta indexación y visibilidad de Hera en los motores de búsqueda, se ha definido una estrategia de SEO que diferencia el tratamiento de la Landing Page, orientada a la conversión de usuarios, frente a la Web Application, enfocada en la usabilidad y gestión de los dispositivos. En ambos casos, se integrarán etiquetas fundamentales: el Title se configurará para reflejar la propuesta de valor única de cada sección, mientras que la Meta Description sintetizará la capacidad de respuesta y prevención de la plataforma para atraer clics relevantes. Se utilizarán Keywords estratégicas como "hogar inteligente", "gestión de dispositivos IOT", "automatizaciones" y "cámaras de seguridad" para captar la intención de búsqueda del segmento objetivo. Esta configuración no solo optimiza el posicionamiento orgánico, sino que también garantiza una presentación coherente y profesional del ecosistema de seguridad en los resultados de búsqueda. 

### 4.2.4. Searching Systems

Hemos usado searching systems en ciertas partes de la aplicación web por ejemplo en el Resumen de Consumo podemos ver una barra para seleccionar donde el usuario va a seleccionar el mes que están ordenados de manera inversa.



El siguiente ejemplo es en el apartado de Notifications donde vemos un filtro que mostrará notificaciones solamente del tipo seleccionado, de esta manera disminuyendo el volumen de la información mostrada para adecuarse a las necesidades del usuario.



### 4.2.5. Navigation Systems

Los Navigation Systems de Hera pueden apreciarse primero en la landing page donde bajando por la página se llega a cada uno de las etiquetas de arriba, a su vez también se puede presionar el botón para ser dirigido a esa sección en particular. 



En la interfaz principal de la página web se navegará en todo su extensión a través de los botones de la barra de la cabecera.
